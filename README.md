# 🎧 Bluetooth Player

**Bluetooth Player** — это лёгкий графический интерфейс Bluetooth-плеера.  
Проект создан как компактное визуальное дополнение к аудиосистемам, мини-ПК и домашним серверам.

---

## 🚀 Возможности

- Визуальное отображение песни и его текста  
- Минималистичный интерфейс  
- Возможность автоматического запуска при старте системы

## 🛠 Требования

- **Linux** (Ubuntu 20.04+ рекомендуется)  
- Bash 5.0+
- Поддержка Bluetooth-адаптера

## 📦 Установка

- Клонируйте репозиторий:
```bash
git clone https://github.com/qbitix/Bluetooth-Player.git
cd Bluetooth-Player
```

- Сделайте скрипты исполняемыми:
```bash
chmod +x start.sh autostart.sh
```

- Запустите вручную:
```bash
./start.sh
```

- или настройте автозапуск:
```bash
./autostart.sh
```

Обложки треков загружаются через iTunes Search API, Spotify API, MusicBrainz и Cover Art Archive. Spotify используется как дополнительный источник, если в `.env` указаны `SPOTIFY_CLIENT_ID` и `SPOTIFY_CLIENT_SECRET`.


## 🖥 Использование

После запуска программа автоматически определяет активное Bluetooth-устройство и отображает визуальный интерфейс.

🔹 Основные функции

- Показ текущего трека и его состояние

- Динамический текст песни (Если есть)
